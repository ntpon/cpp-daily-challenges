# C++ Daily Challenges

A collection of 22 algorithm exercises with 23 standalone C++ examples.

I wrote these exercises in 2021 while learning algorithms and data structures. This is an archive of that practice.

## Run an example

Use a C++17 compiler such as GCC. From the repository root, compile and run Two Sum:

```sh
g++ -std=c++17 two-sum/two-sum.cpp -o /tmp/two-sum
/tmp/two-sum
```

The example prints `0,1`. Each source file has its own `main` and can be compiled separately. Most files use example inputs defined in the source.
